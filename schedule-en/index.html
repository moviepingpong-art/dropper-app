予定表ドロッパー

年間行事予定・大会日程・リーグ戦日程などの予定表をドロップ → 一覧で確認 → Googleカレンダーにまとめて登録

予定をGoogleカレンダーに登録するため、最初にGoogleログインとカレンダー・ドライブの許可が必要です。

読み取り方：
空欄なら予定表の「◯◯年度」から自動で判断します。4〜12月はその年、1〜3月は翌年になります。
ここに予定表ファイルをドラッグ&ドロップ
PDF・画像（JPEG/PNG）対応

⚠ この予定表はカレンダー形式（マス目）のようです。日付と行事名の対応が正しく取れていない可能性があります。下の「AIで読み直す」をお試しください。

読み取れていない予定があるときに使います（APIキーが必要）。

読み取れた文字（先頭のみ）：

🤖 AIで読み取り精度を上げますか？

      
予定表の読み取りは、AIを使うとさらに正確になります。マス目のカレンダー形式はAIでしか読めません。利用は任意です。


      

        
AIを使わない（通常モード）

        
追加設定なしで、いますぐ無料で使えます。読み取り結果はご自身で確認・修正できます。

      


      

        
AIを使う（AIモード）

        
        

          💳 クレカ登録なし
          🆓 無料枠内なら0円
          ⏱ 取得は約3分
        

        
ご自身の Google Gemini APIキー を使って、予定表をAIで読み取ります。

        
    
          
  • 📥 1枚の予定表から何十件・何百件の予定をまとめて読み取ります（実データで157件・211件を確認）。
    • 
          
  • 🔒 キーはお使いの端末内だけに保存されます。当方はサーバーを持っていないため、受け取ることができません。
    • 
          
  • 💳 クレジットカードの登録は不要。無料枠は1日およそ1,500回で、超えても課金されず止まるだけです。
    • 
          
          
  • 🔑 キーの取得方法は こちら（取得ガイド） をご覧ください（クレカ不要・3分・0円の理由も説明しています）。
    • 
        

      


      

        
        
      

      
※あとから「AIモード」を押せば、いつでもキーを入れ直せます。

🔑 Gemini APIキーの設定

      
AIで読み取るには、ご自身のGemini APIキーが必要です。Googleアカウントがあれば無料で取得できます（3分ほど）。クレジットカードの登録は求められません。

      

        💳 クレカ登録なし
        🆓 無料枠内なら0円
        ⏱ 取得は約3分
      

      
      

        
取得のしかた

        
    
          
  1. 下のリンクから Google AI Studio を開く
    2. 
          
  2. Googleアカウントでログインする
    3. 
          
  3. 「APIキーを作成」をクリックする
    4. 
          
  4. できたキーをコピーして、下の欄に貼り付ける
    5. 
        

        Google AI Studio を開く ↗
      

      
      

        
        

          
          
        

      

      
      

      
      

        
🔒 入力したキーの扱い

        
    
          
  • 保存先は、お使いの端末の中（ブラウザ）だけです。他の端末には同期されません。
    • 
          
  • 当方はサーバーを持っていないため、キーも読み取った内容も受け取れません。
    • 
          
  • 送信先は Google の Gemini API だけです。やめたいときは Google AI Studio でキーを削除すれば、その場で無効になります。
    •
