# 申込書ドロッパー — 中核の確認用

`entry-xlsx.js`（xlsx の読み書き）・`entry-roster.js`（名簿・名前の突き合わせ・書き込む値）・
`entry-rules.js`（見出しの語から欄の対応を作る）・`entry-map.js`（対応を検めて名前に当てはめる）・
`entry-postal.js`（郵便番号 ⇄ 住所）・`entry-attend.js`（出欠システムから名前を取り込む）・
`entry-book.js`（名簿ファイル）と `tools/make-postal.js`（郵便番号データの変換）を、
画面を通さずに Node で確かめるためのものです。

## 使い方

```
node entry/test/make-fixtures.js                          試験用データを作り直す（fixtures/）
node entry/test/run.js                                    確かめる。落ちたら終了コード 1
powershell -ExecutionPolicy Bypass -File entry/test/excel-check.ps1   本物の Excel で開いて確かめる
```

`excel-check.ps1` は `run.js` が `out/` に書き出したファイルを開きます。先に `run.js` を流してください。
Excel の入っている PC でだけ動きます。

## 郵便番号データを入れ替える

住所の自動入力は、日本郵便の郵便番号データを変換した `entry/postal/0.json`〜`9.json`（郵便番号 → 住所）と
`entry/postal/rev/01.json`〜`47.json`（住所 → 郵便番号）を使います。どちらも同じスクリプトが作ります。
日本郵便はこのデータについて「著作権を主張しません。自由に配布していただいて結構です」としています。

1. [住所の郵便番号（1レコード1行、UTF-8形式）](https://www.post.japanpost.jp/service/search/zipcode/download/utf-zip.html) から
   `utf_ken_all.zip` を取り、リポジトリの**外**に展開する（CSV はリポジトリに入れない）
2. ページに書いてある更新日を付けて変換する

```
node tools/make-postal.js <展開した utf_ken_all.csv> 2026-08-31
node entry/test/run.js
```

変換の最後に出る数が前回から大きく変わっていたら、差分を見てから入れる
（2026-08-31 更新: 郵便番号 120,717 個・候補が2つ以上 1,267 個／逆引きは住所 119,163 種類・
番号が2つ以上 1,063 種類）。データは合わせて約 9MB。

## 画面を手元で試す

```
python -m http.server 8130 --bind 127.0.0.1        （リポジトリの直下で）
```

**★ ポートは 8130 にする**（2026-09-16）。出欠システムの API は呼び出してよいサイトを決めていて
（`hakusan-attendance` の `ALLOW_ORIGINS`）、`app.dropper-tools.com` と **`127.0.0.1:8130` / `localhost:8130`** しか
入っていない。8765 で立てると「出欠システムから取り込む」だけが必ず失敗する（ほかの機能は動くので気づきにくい）。

`http://127.0.0.1:8130/entry/` を開き、`fixtures/` の様式と名簿を入れる。
**空の申込書から選ぶ道**は `fixtures/form-d-blank.xlsx`（もともと空）か、本物の様式の名前を消した写しで試す。
`out/local-typed.xlsx`（`run.js` が作る、本物の百万石に架空の名前を書いた版）も入れられる。
名前が書き込まれた本物の申込書を画面で試すときは、名前の欄を架空の名前に置き換えた写しを `out/` に作って使う
（2026-09-15 はスポレク参加申込書をこの形で試した）。

## 本物の様式で試す（local/）

大会の申込書は主催者の文書なので、リポジトリには入れません。
`entry/test/local/` に置くと `run.js` が拾います（`.gitignore` 済み）。無ければその項目だけ飛ばします。
いまはファイル名に「百万石」「スポレク」を含む `.xlsx` を探します。

- **local/ にも本物の名簿は置かないこと。** 試験は架空の名簿で流します
- **★ スポレク参加申込書には、本物の名前が書き込まれている。** 試験では名前の欄（B10・B13〜B18）を
  架空の名前に置き換えてから使う。**本物の名前を表示しない・書き出さない・試験の期待値に書かない**

## 踏んだ罠

### 欄の対応を AI（Gemini）に作らせていた頃（2026-09-15 にやめた）

やめた理由と測った数字は `CLAUDE.md` と保管庫の作業ログ。規則にしても役に立つ教訓だけ残す。

- **★ 名簿に無い人の名前は、伏せ字から漏れる。** 伏せ字は「名簿と一致した名前」と「名前の並びの中の誤字」しか
  拾わないので、連絡責任者のように別の表にいる名簿外の人の名前は、AI に送る本文にそのまま残った。
  AI をやめた決め手。**戻すなら、ここを先に塞ぐこと**
- **★ 読み取りが1行ずれると、黙って間違った申込書ができる。** Gemini が生年月日の4欄を名前の1行下と答えた。
  書き込み先は2人目の空欄なので「文字の入った欄には書かない」をすり抜ける。
  **名前の行の間隔から1人ぶんの行数を測り、それ以上ずれた指示は書かない**（`offset-crosses-person`）。規則でも外さない
- 列を「C14」「C:E」の形で答えてきた（氏名が C14:E14 の結合セル）。先頭の英字を採る
- 様式に書き方の手がかりが無いと既定（和暦）を選ぶ。期待値を甘くするより、**様式に記入例を置いて手がかりを与える**

### 見出しの規則

- **★ 規則は、作った人が中身を知っている様式で測ると当たりすぎる。** 自作の様式と百万石では 160/160 だったが、
  初めて見たスポレク参加申込書では 78欄中42欄だった（同じ列に上下2つの表があるのを1つにまとめた）。
  **規則を変えたら、初めての申込書でも測ること。** 7 の「見出しの書き方を変えた6通り」も、規則を変えずに作った
- **★ 漏れを探す確認は、説明文ではなくデータの部分に向ける。** 説明文に書き方の例「1950/4/1」があり、
  「生年月日が載っている」と誤って落ちたことがある
- **★ 表の鍵に「名前を書き始めた行」を入れない**（2026-09-15）。2行目から名前を書くと、1行目の番号「1」を見出しと
  取り違えて鍵が変わり、覚えた直しが効かなくなった。数字だけの文字は見出しと見なさず、空いた記入行の上まで見出しを探す。
  **直す前の規則に戻して流すと、この試験は落ちる**ことを確かめてある
- **★ No. の列を「決められなかった列」に並べると、どの申込書でも毎回警告が出る。** 名前の行すべてに印刷済みの列は一覧に出さない

### 名簿ファイル

- **★ 「書いて読み直したら同じ」だけでは、書式の間違いを見抜けない**（2026-09-16）。郵便番号を文字の書式にせず
  書いても、生年月日を日付ではなく文字で書いても、往復の試験は通ってしまう（どちらも Excel では困る）。
  わざと壊して初めて気づいた。セルの書式（`numFmtId`・`isDate`）そのものを見る試験を足してある
- 見出しを変えたファイルは読まない。これは不便ではなく主旨（推測をやめたのがこの作りの理由）

### 郵便番号データ

- **★ 町域名は、そのまま住所に書けない。** 「以下に掲載がない場合」「○○市の次に番地がくる場合」「○○村一円」
  「常盤（その他）」「中央アエル（１階）」が混じる。ただし多賀町の「一円」は本当の地名（2026-09-16 に数えた）
- **★ 1つの郵便番号が1つの住所とは限らない。** 括弧を取り除くと 1,267 個で町域が2つ以上残り、134 個は市区町村から違う。
  1つに決めずに候補を並べる
- **★ 試験が途中で止まると、NG の行が出ないまま落ちる。** わざと壊して試したとき、NG の行だけを数えていたので
  「落ちなかった」と読み違えかけた（本当は終了コード 1 で止まっていた）。Promise の失敗も NG として書くこと

### 出欠システムからの取り込み

- **★ 呼び出しの合図は `action=members`。`a=members` ではない**（2026-09-16 に踏んだ）。
  知らない合図だと出欠システムは「行事の一覧」を返す。**`ok` は true なのに名簿が入っていないので、
  画面には「0人」と出るだけ**で、間違いに気づけない。**返事の形（`members` が配列か）まで確かめること**

- **★ 出欠システムには名前と性別しか無い。** 生年月日・住所・電話は取り込めないので、名簿の画面で足してもらう
- **★ 出欠の名前は空白なしのことがある**（「鈴木花子」）。姓と名に分けられない人は、取り込みの画面で直せる。
  間違った位置で勝手に切らない
- 呼び名が入っていることがあり得る（正式な氏名とは限らない）

### 空の様式から表を見つける（2026-09-18）

- **★ 規則は、自分で作った様式で測ると当たりすぎる。** 11 の数字（11/11）には、こちらが PDF を見て起こした
  様式（かほく市長杯・様式D）が含まれる。**本物の Excel の申込書が手に入ったら測り直すこと**
- **★ 表の下に空けてある行を数えてしまう。** スポレクの11行目（罫線だけの空行）。
  セルの並び（どの列にセルがあるか）が変わったら終わり、とした
- **★ 行の左の「監督」「選手」を見出しと取り違えると、表ごと見つけられない**（百万石）。
  名前の列より左の短い文字は行の名札とみなす
- 見た目の罠: **同姓同名は、選ぶボタンに生まれ年を出さないと見分けられない**

### 事務局の様式そのものの癖

- **★ 見出しに空白を入れた様式がある**（「氏　名」「氏　　　名」）。2026-09-18 まで、名前の並びのすぐ上に
  その見出しがあると**見出しを名前として拾っていた**（スポレクと百万石は見出しが表から離れていて助かっていた）。
  見出しの語は**空白を取ってから**見る
- **★ 基準日の言い回しは「現在」「時点」だけではない。**「年齢の基準は、令和9年4月1日とする」もある
  （かほく市長杯）。申込日は拾わない

- **★ 年齢の欄に日付の書式が付いていることがある**（2026-09-18、本物のスポレク参加申込書で発見）。
  そこへ年齢の 60 を書くと、Excel は **「1900-02-29」** と表示する（値は正しく、見え方だけが壊れる）。
  数を書くセルが日付の書式なら、そのセルだけ書式の写しを作って外す。
  `fixtures/form-c-split.xlsx` の G7 に同じ罠を仕込んである
- 年齢の基準日が書かれていない様式がある（スポレク）。④で本人に入れてもらう。入れるまで年齢は「書けません」
- **★ ブックに部品を足すには、種類の宣言が要る**（2026-09-20）。OPC は全部品の種類を
  `[Content_Types].xml` で宣言する決まりで、宣言の無い部品が1つあるだけで **Excel は開かない**。
  最初これに気づかず、Excel COM の不調を疑って時間を使った。**「既知の良いファイル」で
  COM が動くことを先に確かめる**と、どちらの問題か分かる
- **★ 印刷範囲は「シート名」ではなく「並び順の番号」で紐づく**（`localSheetId`）。
  シートを途中に挿すと後ろがずれ、**別のシートの印刷範囲になる**。本物の百万石でしか出ない罠。
  見た目は何も変わらないので、Excel COM で `PageSetup.PrintArea` を読んで確かめる
- **★ 斜線（×印）は「ここは書かなくてよい」という事務局の書き方**（2026-09-19、本物の百万石 団体戦で発見）。
  監督の行の生年月日・年齢に斜線が引いてあるのに書き込んでしまった。**罫線を見て分かる**が、
  `<diagonal/>`（空）は**どの罫線にも必ず入っている**ので、`style=` が付いているかで見ること。
  そこを見落とすと全部の欄が斜線扱いになり、何も書けなくなる。
  同じとき「昭和の文字がずれた」とも見えたが、これは**様式がもともと監督の行だけ 11pt** だったため（こちらは直していない）

### ファイルと Excel

- **★ 壊したファイルで確認スクリプトを試すときは、壊せたことを先に確かめる**（2026-09-15）。
  存在しないセルを狙って置き換えが空振りし、壊れていないファイルを「Excel は壊れていても開く」と
  読み違えかけた。さらにシェルのヒアドキュメントで JS を書き出したら `\\` が `\` に潰れ、
  正規表現が別物になっていた。スクリプトはファイルとして書き、置き換えの前後を比べること
- **★ 作業ツリーのファイルは CRLF のことがある**（`core.autocrlf = true`）。複数行の文字列で置き換えるときは、
  改行をそろえてから探す。そろえずに探して空振りし、差し替えが途中で止まったことがある
- **★ `excel-check.ps1` の `Workbooks.Open` に `[Type]::Missing` を並べない。**
  すべてのファイルが「開けない」になる。引数は3つまでにしてある
- **★ `.ps1` は英数字だけで書く。** Windows PowerShell 5.1 は BOM の無い `.ps1` を CP932 で読む。
  日本語の期待値は `out/expect.json`（UTF-8）から読む
