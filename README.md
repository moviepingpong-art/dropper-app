# dropper-app — ドロッパーシリーズ

チラシや予定表を**ドラッグ&ドロップするだけ**で内容を読み取り、そのまま **Google カレンダー**に
登録できる Web ツールです。用途の違う2本を、同じリポジトリで公開しています。

| ツール | 読み取るもの | 登録される予定 |
|---|---|---|
| 🎪 **イベントドロッパー** | 大会要項・公演チラシなど **1枚＝1イベント** | 1件 |
| 📅 **予定表ドロッパー** | 年間行事予定・大会日程など **1枚＝N件** | まとめて何十件も |

サーバーを持たない**静的サイト**で、GitHub Pages で公開しています。

# 🎪 イベントドロッパー

大会要項（PDF・画像）から、大会名・日程・会場などを読み取り、Google カレンダーに1件の予定として
登録します。

## 対応するイベントの種類

画面上部のセレクタで種類を選ぶと、項目名・抽出のしかた・案内文がその種類に合わせて切り替わります。

| 種類 | 主な用途 | 特徴 |
|---|---|---|
| 🏓 スポーツ大会 | 各競技の大会要項 | 競技セレクタ・試合形式 |
| 🎵 コンサート・発表会・舞台 | 公演チラシ | 開場／開演・演目・出演者 |
| 🖼️ 展示会・個展 | 展覧会チラシ | **会期（初日〜最終日）**・開館時間 |
| 🎓 講演会・セミナー・教室 | 講座の案内 | 演題・講師・定員・オンライン |
| 🎪 祭り・地域の催し | 祭り・マルシェ等 | 開催時間・荒天時の扱い |
| 🎉 その他イベント | 上記以外 | 汎用の読み取り |

## できること

1. **種類と競技を選ぶ** — 内容に合わせて読み取りを最適化します。
2. **チラシ・要項ファイルをドロップ** — PDF・画像（JPEG/PNG）に対応。複数まとめてドロップも可。
3. **内容を確認・修正** — 大会名・開催日・試合形式・会場などを画面上で確認して直せます。
4. **Google カレンダーに登録** — 確認した内容をそのまま予定として追加します。
   要項ファイルは Google ドライブの `DropperFiles` フォルダに保存され、予定にリンクが添付されます。
5. **案内文ジェネレーター** — 大会の案内文を生成し、LINE などで共有できます。
   共有リンクはタップでカレンダー追加／地図表示につながります。

## 読み取りの2モード

- **通常モード** — 追加設定なしで、すぐ無料で使えます。Google の OCR で変換し、必要項目を抽出します。
- **AIモード（任意）** — AI で全項目を読み取ります。精度が上がります。

# 📅 予定表ドロッパー

年間行事予定表・大会日程・リーグ戦日程など、**たくさんの予定が並んだ1枚**を読み取り、
一覧で確認してから Google カレンダーへ**まとめて登録**します。

## できること

1. **年度を入れる** — 予定表には年の記載が無いことが多いため、年度の入力欄があります。
   空欄なら予定表の「◯◯年度」から自動で判断します（4〜12月はその年、1〜3月は翌年）。
2. **予定表ファイルをドロップ** — PDF・画像（JPEG/PNG）に対応。
3. **一覧で確認・修正** — 開催日・終了日・時刻・行事名・場所が表で並びます。
   登録したくない行はチェックを外せます。日付が年度から外れている行には ⚠ を付けて知らせます
   （勝手に直さず、確認していただく方針です）。
4. **まとめて登録** — チェックの付いた行を Google カレンダーへ追加します。
   登録できた行はチェックが外れるので、二重登録になりません。

## 読み取りの2モード（役割が違います）

- **通常モード** — Google の OCR で文字にしてから抽出します。3列の表など、
  **行ごとに予定が並ぶ形式**の予定表向けです。追加設定なしで使えます。
- **AIモード** — OCR を通さず、**PDF・画像そのものを AI に渡します**。
  学校の年間行事予定表のような**マス目のカレンダー**は、文字にした時点で日付と行事名の対応が
  失われてしまうため、こちらでないと読み取れません。

## 予定の登録について

- 時刻の無い予定は**終日の予定**として登録します。
- 時刻があって期間が無い予定は、**1時間**の予定にします。
- 期間と時刻の両方が読み取れたときは、**期間を優先**します（日数のほうが失うと痛いため）。

# 共通のしくみ

## AIモードのAPIキー（BYOK）

どちらのツールも、AIモードには利用者ご自身の **Google Gemini APIキー**を使います
（BYOK：Bring Your Own Key）。Googleアカウントがあれば無料で取得できます。

- キーは**利用者の端末内（ブラウザ）だけに保存**され、当方のサーバーには送信も保存もしません。
- キーは2本のツールで共通です。片方で設定すれば、もう片方でもそのまま使えます。

## プライバシー

- 処理は**利用者のブラウザ内で完結**します（当方のサーバーはありません）。
- Gemini APIキーや読み取り結果を、当方が収集・保存することはありません。
- Google カレンダー／ドライブへのアクセスは、利用者自身の認可（OAuth）にもとづいて行われます。
  2本のツールは同じ認可を共有し、求める権限も同じです。
- 詳細は[プライバシーポリシー](https://dropper-tools.com/privacy.html)をご覧ください。

## 構成

```
calendar/      イベントドロッパー 日本語版（app.js / parser.js / i18n.js / index.html）
calendar-en/   イベントドロッパー English 版
calendar-in/   イベントドロッパー Hinglish 版
add/           案内文リンク用の中継ページ（言語共通）
schedule/      予定表ドロッパー 日本語版
               index.html / schedule-parser.js（通常モード）
               schedule-ai.js（AIモード） / schedule-app.js（画面・OCR・一括登録）
CNAME          カスタムドメイン設定（app.dropper-tools.com）
.nojekyll      GitHub Pages の Jekyll ビルドをスキップ
```

- イベントドロッパーの `app.js` `parser.js` `i18n.js` は **3言語フォルダで完全同一**です。
- `index.html` は `window.LANG` の値だけが異なります。

## 技術

- Google Identity Services（OAuth）／ Google Calendar API ／ Google Drive API
- Google Gemini API（利用者の BYOK：Bring Your Own Key、任意）
- ホスティング: GitHub Pages（カスタムドメイン `app.dropper-tools.com`）
